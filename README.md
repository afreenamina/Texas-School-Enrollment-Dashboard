# Texas Public School Enrollment Dashboard

## Project Overview

This project analyzes Texas public school enrollment data for the
2023–24 and 2024–25 school years using Power BI.

The dashboard provides an interactive view of enrollment across
Texas school districts, campuses, counties, and campus types.

## Dashboard Features

- Total enrollment by school year
- Enrollment by campus type
- Top 10 Texas school districts by enrollment
- Total number of campuses
- Average enrollment per campus
- Largest district enrollment
- County filtering
- School year filtering
- Interactive dashboard visuals

## Key KPIs

- Total Enrollment
- Total Campuses
- Average Enrollment per Campus
- Largest District Enrollment

## Tools Used

- Power BI
- Power Query
- DAX
- Git
- GitHub

## Data Preparation

The data was cleaned and transformed using Power Query.

Key transformations included:

- Removing unnecessary columns
- Renaming columns
- Changing data types
- Removing duplicate records
- Creating campus type names
- Combining enrollment data across school years
- Creating relationships between reference and enrollment data

## Dashboard

The Power BI dashboard compares Texas public school enrollment
between 2023–24 and 2024–25.

Users can interact with the dashboard using:

- School Year slicer
- County slicer
- District Name slicer
- Interactive charts and KPI cards
